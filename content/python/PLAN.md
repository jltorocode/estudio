# Python de cero a experto — plan del curso

**Alumno:** hispanohablante, empieza desde cero en programación y quiere llegar a nivel experto. Estudia solo, en una plataforma propia donde **todas las prácticas se hacen en el navegador** con Python 3.14 real (Pyodide).

**Principio clave de progresión:** cada sección solo puede dar por sabido lo de las secciones anteriores. Si necesitas algo de una sección posterior, no lo uses (o dilo explícitamente como "lo veremos en la sección X"). Los ejercicios también respetan esto: en s03 no se usan funciones con parámetros por defecto ni comprensiones; en s02 no hay bucles, etc. Excepción: desde s01 se usa `def` mínimo para envolver ejercicios (ver s01).

**Tono:** claro, cercano, preciso. Explica el *porqué*, no solo el *cómo*. Usa analogías cuando ayuden, errores típicos, buenas prácticas (PEP 8), y compara con cómo lo haría un experto. Nada de relleno.

**Referencias base:** documentación oficial (https://docs.python.org/3/ — tutorial, library reference, language reference, HOWTOs, "What's New in Python 3.10…3.14"), PEPs relevantes (8, 20, 257, 484, 526, 557, 572, 585, 604, 634–636, 654, 695, 703, 709, 742, 749, 750…), y para certificaciones las guías del Python Institute (PCEP, PCAP, PCPP1). Contrasta con fuentes reconocidas (Real Python, *Fluent Python* 2ª ed. como referencia conceptual, PyCon talks). Verifica versiones: lo que es nuevo en 3.12/3.13/3.14 se dice.

## Niveles (campo `domain`)
- `basico` — **Nivel 1 · Fundamentos** (s01–s06). Cubre lo del PCEP.
- `intermedio` — **Nivel 2 · Intermedio** (s07–s12). Cubre lo del PCAP.
- `avanzado` — **Nivel 3 · Avanzado** (s13–s16). Parte del PCPP1 y práctica profesional.
- `experto` — **Nivel 4 · Experto** (s17–s19).
- `extra` — **Examen final** (s20).

## Secciones y alcance

### s01 · Primeros pasos con Python (`basico`)
Qué es programar y qué es Python (interpretado, alto nivel, multiparadigma, "baterías incluidas", Zen de Python `import this`), dónde se usa. Cómo se ejecuta: intérprete CPython, código fuente → bytecode → máquina virtual (a nivel intuitivo). Instalación en tu ordenador (python.org, Microsoft Store, Homebrew; `uv` como opción moderna), comprobar versión, REPL (`>>>`), ejecutar un script `.py`, VS Code + extensión Python (explicado, no practicable en el navegador). Cómo funciona esta plataforma (editor, Ejecutar, Comprobar, tests). `print()` (sep, end), `input()` (siempre devuelve str), comentarios, errores de sintaxis vs errores en ejecución, cómo leer un *traceback*. Indentación como sintaxis. **Introducción mínima a `def`**: "una función es un bloque con nombre; en los ejercicios escribirás el código dentro de `def main():` o de una función que devuelve un valor" — solo lo imprescindible, sin parámetros por defecto ni ámbito (eso es s06). Ejercicios: imprimir con formato exacto, pedir datos con input (usando `capturar`), leer tracebacks.

### s02 · Variables, tipos y operadores (`basico`)
Variables como nombres que apuntan a objetos (modelo de referencias, `id()`, `type()`), asignación múltiple e intercambio, convenciones de nombres (PEP 8), palabras reservadas. Tipos básicos: `int` (precisión arbitraria), `float` (IEEE 754, `0.1 + 0.2`, `round`, `math.isclose`), `complex` (breve), `bool`, `None`, `str` (básico). Conversión (`int()`, `float()`, `str()`, `bool()`), truthiness. Operadores aritméticos (`/` vs `//` vs `%` con negativos, `**`, `divmod`), asignación aumentada, comparación (encadenada), lógicos con cortocircuito (y qué devuelven `and`/`or`), identidad (`is` vs `==`), pertenencia (`in`) introductorio, precedencia. f-strings básicas. Módulo `math` básico. Tipado dinámico pero fuerte. Sin bucles ni if (eso es s03). Ejercicios: cálculos (IMC, conversiones de temperatura, división con resto, redondeo), expresiones booleanas.

### s03 · Control de flujo (`basico`)
`if/elif/else`, expresión condicional (ternaria), condiciones compuestas, `match`/`case` (patrones literales, capturas, OR, guardas; los patrones de clases y mapeos con más detalle se retoman en s11), `while` (centinela, contadores, acumuladores), `for` con `range()` y sobre cadenas, `break`, `continue`, `else` en bucles, `pass`, bucles anidados, operador morsa `:=` (uso razonable). Trazado de código a mano, diagramas de flujo. Ejercicios clásicos: FizzBuzz, números primos, dígitos de un número, adivinar un número con entradas, tablas de multiplicar, validaciones.

### s04 · Colecciones: listas, tuplas, diccionarios y conjuntos (`basico`)
Secuencias: listas (métodos, indexación negativa, slicing con paso, mutabilidad, `sort` vs `sorted` con `key` y `reverse`, `len/min/max/sum`), tuplas (inmutabilidad, empaquetado/desempaquetado, `*resto`), `range` como secuencia. Diccionarios (creación, acceso, `get`, `setdefault`, iterar `items/keys/values`, orden de inserción, borrar, fusionar con `|`), conjuntos (operaciones de conjuntos, `frozenset`, eliminar duplicados). Comprensiones de lista/dict/set **básicas** (las de generador y avanzadas en s12). Copia superficial vs profunda (`copy`), aliasing, el error de la lista como valor compartido. `enumerate`, `zip`, `reversed`, `any`/`all`. Estructuras anidadas (lista de dicts). Complejidad intuitiva (buscar en lista vs dict/set). Ejercicios: estadísticas de una lista, frecuencia de palabras, agenda de contactos, matrices, eliminar duplicados manteniendo orden, agrupar.

### s05 · Texto a fondo: cadenas, formato y expresiones regulares (`basico`)
`str` inmutable, indexación/slicing, métodos (split/join/strip/replace/find/startswith/upper/…), `in`, comparación de cadenas, iterar caracteres. f-strings avanzadas: especificación de formato (ancho, alineación, relleno, decimales, `%`, separador de miles, `=` para depurar, `!r`), `str.format` y `%` (reconocerlos). Unicode: code points, `ord/chr`, normalización (`unicodedata`) y acentos, `casefold`. `bytes` y codificaciones (UTF-8, `encode/decode`, errores). Plantillas `t"…"` (template strings, nuevo en 3.14, PEP 750) a nivel introductorio. Expresiones regulares con `re` (search/match/fullmatch/findall/sub/split, grupos con nombre, flags, raw strings, cuándo NO usar regex). Ejercicios: palíndromos con acentos, contar vocales, validar emails/códigos postales con regex, formatear tablas de texto, cifrado César, slugify.

### s06 · Funciones (`basico`)
`def` completo, `return` (múltiples valores como tupla, `None` implícito), parámetros posicionales y nombrados, valores por defecto (y la trampa del valor mutable por defecto), `*args`, `**kwargs`, parámetros solo-posicionales `/` y solo-nombrados `*`, desempaquetado en llamadas. Ámbito LEGB, `global`, `nonlocal` (introductorio; closures a fondo en s12), funciones como objetos de primera clase, funciones de orden superior (`map`, `filter`, `sorted(key=)`), `lambda`. Recursión (caso base, pila de llamadas, límite de recursión, cuándo usar iteración). Docstrings (PEP 257) y anotaciones de tipo básicas (`def f(x: int) -> str`; tipado a fondo en s13). Diseño de funciones: pureza, efectos secundarios, una responsabilidad. Ejercicios: factorial/fibonacci iterativo y recursivo, validadores, calculadora con kwargs, aplanar listas anidadas recursivamente, ordenar por varios criterios.

### s07 · Módulos, paquetes y entornos (`intermedio`)
Módulos (`import`, `from … import`, alias, `__name__ == "__main__"`), cómo se buscan (`sys.path`), caché de módulos, paquetes (`__init__.py`, imports relativos/absolutos, namespace packages), `__all__`. Tour de la biblioteca estándar útil (`math`, `random` con semilla, `statistics`, `datetime` breve, `os`, `sys`, `pathlib` breve, `collections` breve, `itertools` breve — sin profundizar lo que tiene su sección). Entornos virtuales (`venv`), `pip` y `requirements.txt`, `pyproject.toml` y `uv` (gestor moderno) — explicado con bloques no ejecutables; PyPI. Estructura de un proyecto pequeño. Ejercicios en el navegador: crear un módulo escribiéndolo en disco (en `setup` o en el código) e importarlo, usar `importlib.reload`, `random.seed` reproducible, organizar funciones en "módulos".

### s08 · Errores, excepciones y depuración (`intermedio`)
Tipos de errores, jerarquía de excepciones (`BaseException` vs `Exception`), `try/except/else/finally`, capturar varias, `as e`, relanzar (`raise`, `raise … from …`), excepciones personalizadas (jerarquías propias con atributos), EAFP vs LBYL, `assert` (y por qué no validar datos con él), `ExceptionGroup` y `except*` (3.11), notas en excepciones (`add_note`), limpieza con `finally` y `with` (introductorio). `warnings`. Depuración: leer tracebacks complejos, `print` vs `logging` (niveles, configuración básica), `breakpoint()`/`pdb` (explicado), estrategias de depuración. Ejercicios: conversión robusta de entradas, validación con excepciones propias, reintentos, parser tolerante a errores, agregar errores en grupos.

### s09 · Archivos y datos (`intermedio`)
Archivos de texto y binarios (`open`, modos, codificación, `with`), leer por líneas grandes archivos, `pathlib` a fondo (rutas, glob, crear/borrar, leer/escribir), CSV (`csv.reader/DictReader/DictWriter`, dialectos), JSON (`json.load/dump`, tipos, indentación, serializar objetos propios con `default`), `datetime`, `date`, `timedelta`, `zoneinfo` (zonas horarias, conscientes vs ingenuas), formateo y parseo de fechas (ISO 8601), `sqlite3` básico (conexión, consultas parametrizadas, transacciones — nunca concatenar SQL), `zipfile`/`shutil` breve, `tempfile`. Ejercicios: procesar un CSV de ventas, convertir CSV↔JSON, log de eventos con fechas, inventario en SQLite, calcular edades y diferencias horarias entre zonas.

### s10 · Programación orientada a objetos I (`intermedio`)
Por qué objetos. Clases e instancias, `__init__`, atributos de instancia vs de clase, métodos, `self`, métodos de clase (`@classmethod`, constructores alternativos) y estáticos, encapsulación por convención (`_`, `__` name mangling), `@property` con getter/setter y validación, herencia, `super()`, sobrescritura, polimorfismo y *duck typing*, composición vs herencia, `isinstance`/`issubclass`, `__str__`/`__repr__` (básico; resto del modelo de datos en s11). Diseño: responsabilidades, cohesión. Diagramas de clases UML. Ejercicios: cuenta bancaria con validaciones, figuras geométricas con polimorfismo, inventario con composición, jerarquía de empleados, carrito de compra.

### s11 · POO II: el modelo de datos de Python (`intermedio`)
Métodos especiales (dunder): representación, comparación (`__eq__`, `__lt__`, `functools.total_ordering`), `__hash__` y su relación con `__eq__`, aritméticos y reflejados, `__bool__`, `__len__`, contenedores (`__getitem__`, `__contains__`, `__iter__`), `__call__`, protocolo de contexto (`__enter__/__exit__`). `dataclasses` a fondo (field, default_factory, frozen, order, slots, kw_only, `__post_init__`), `enum` (Enum, IntEnum, StrEnum, Flag, auto), clases abstractas (`abc`), `typing.Protocol` (tipado estructural, introductorio), `__slots__`, herencia múltiple y MRO (C3), mixins. `match` con patrones de clase y mapeo. Ejercicios: vector 2D con operadores, fracciones, baraja de cartas iterable, dataclass de pedido inmutable, máquina de estados con Enum, colección personalizada tipo lista.

### s12 · Iteradores, generadores, decoradores y estilo funcional (`intermedio`)
Protocolo de iteración (iterable vs iterador, `iter`/`next`, `StopIteration`), generadores (`yield`, evaluación perezosa, pipelines, `yield from`, `send` breve), expresiones generadoras, comprensiones avanzadas (anidadas, con condiciones; legibilidad), `itertools` (count, cycle, chain, islice, groupby, product, permutations, combinations, accumulate, batched 3.12, pairwise), `functools` (reduce, partial, lru_cache/cache, wraps, singledispatch), closures a fondo, decoradores (simples, con argumentos, apilados, `functools.wraps`, decoradores de clase introductorio), context managers con `contextlib` (`contextmanager`, `suppress`, `ExitStack`), `operator`. Ejercicios: generador de primos infinito, pipeline de logs con generadores, decorador de reintentos/tiempo/memoización, agrupar con groupby, `@contextmanager` para temporizar.

### s13 · Tipado estático y calidad de código (`avanzado`)
Type hints a fondo: tipos integrados genéricos (`list[int]`), `X | None`, `Optional`, `Union`, `Callable`, `Iterable/Sequence/Mapping` de `collections.abc`, `TypedDict`, `Literal`, `Final`, `Annotated`, `TypeAlias` y `type X = …` (3.12), genéricos con la sintaxis `[T]` (PEP 695), `TypeVar` con límites, `Protocol`, `@overload`, `Self`, `TypeGuard`/`TypeIs`, evaluación diferida de anotaciones (3.14, PEP 649/749), `typing.get_type_hints`. Verificadores (mypy, pyright) y linters/formateadores (Ruff) — explicados con bloques no ejecutables y su configuración en `pyproject.toml`. Pruebas: `unittest` (práctica en el navegador) y `pytest` (explicado: fixtures, parametrize, marcas), dobles de prueba con `unittest.mock`, cobertura, TDD, `doctest`. Clean code, PEP 8, docstrings de estilo Google/NumPy. Ejercicios: tipar correctamente funciones dadas y validar con `get_type_hints`, escribir casos `unittest` que el test ejecuta, usar `mock.patch`, TDD guiado de una función, doctests.

### s14 · Concurrencia y programación asíncrona (`avanzado`)
Conceptos: concurrencia vs paralelismo, I/O-bound vs CPU-bound, procesos e hilos, el GIL y por qué existe, Python *free-threaded* (3.13 experimental, 3.14 soportado — PEP 703/779) y subintérpretes (`concurrent.interpreters`, 3.14 — PEP 734) a nivel informativo. `threading` (Thread, Lock, condiciones de carrera, Queue), `multiprocessing` y `concurrent.futures` (ThreadPoolExecutor, ProcessPoolExecutor) — **explicados con bloques no ejecutables** (el navegador no permite hilos). `asyncio` a fondo **con práctica**: corrutinas, `await`, event loop, tareas, `gather`, `TaskGroup` (3.11), cancelación, timeouts (`asyncio.timeout`, `wait_for`), `asyncio.Queue` productor/consumidor, semáforos para limitar concurrencia, sincronizar vs async, `async for`/`async with`, generadores asíncronos. Cuándo usar cada modelo (tabla de decisión). Ejercicios (todos con `await` en los tests): descargas simuladas con `asyncio.sleep` en paralelo, limitar concurrencia con Semaphore, productor/consumidor, timeouts con reintentos, pipeline asíncrono.

### s15 · Rendimiento, estructuras de datos y algoritmos (`avanzado`)
Notación Big-O y coste real de las operaciones de las estructuras integradas (tabla oficial de complejidad), medir antes de optimizar (`timeit`, `time.perf_counter`, `cProfile`/`pstats`, `tracemalloc`), `collections` a fondo (deque, Counter, defaultdict, OrderedDict, ChainMap, namedtuple), `heapq`, `bisect`, `array`, `memoryview` breve, caché (`lru_cache`), algoritmos esenciales implementados en Python (búsqueda binaria, ordenaciones y por qué usar `sorted`, dos punteros, ventana deslizante, BFS/DFS en grafos, programación dinámica, backtracking), patrones de entrevista técnica. Consejos de rendimiento idiomáticos (evitar concatenaciones cuadráticas, comprensiones, sets para pertenencia, generadores para memoria). Ejercicios: top-k con heapq, LRU con OrderedDict, búsqueda binaria de límites, caminos en grafos, DP (mochila / subsecuencia común), detectar anagramas eficientemente, medir con `timeit` y elegir la versión rápida.

### s16 · Cómo funciona Python por dentro (`avanzado`)
CPython: compilación a bytecode (`dis`, `compile`, objetos código), la máquina virtual de pila, el intérprete especializado adaptativo (3.11+, PEP 659) y el JIT experimental (3.13+) a nivel informativo. Todo es un objeto: `PyObject`, identidad/tipo/valor, conteo de referencias (`sys.getrefcount`), recolector de basura cíclico (`gc`), `weakref`, internado de cadenas y enteros pequeños (por qué no usar `is` con literales), mutabilidad y hash. Espacios de nombres y resolución de nombres al detalle (`locals()`, `globals()`, `__builtins__`), cómo funciona `import` por dentro (finders/loaders, `sys.modules`), cómo se ejecuta una llamada a función (frames, `sys._getframe` con cautela), el GIL a nivel de implementación. Ejercicios: analizar bytecode con `dis` y responder preguntas, detectar ciclos y liberarlos con `weakref`, medir memoria de estructuras (`sys.getsizeof`, `tracemalloc`), implementar un importador simple o un caché con `weakref.WeakValueDictionary`.

### s17 · Metaprogramación (`experto`)
Introspección (`type`, `dir`, `vars`, `getattr/setattr/hasattr`, `inspect`: firmas, miembros, código fuente), atributos dinámicos (`__getattr__`, `__getattribute__`, `__setattr__`, `__delattr__`), descriptores a fondo (protocolo `__get__/__set__/__set_name__`, data vs non-data, cómo funcionan `property`, métodos y `classmethod` por debajo), decoradores de clase, `__init_subclass__` (registro de plugins), `__class_getitem__`, metaclases (qué son, `type` como metaclase, `__new__` vs `__init__`, `__prepare__`, casos de uso reales y cuándo NO usarlas), creación dinámica de clases con `type()`, `exec`/`eval` y sus riesgos, módulo `ast` (analizar y transformar código). Ejercicios: descriptor de validación tipado, ORM mínimo con descriptores + `__init_subclass__`, registro de plugins, proxy con `__getattr__`, metaclase singleton/registro, analizador de funciones con `ast` que cuenta llamadas.

### s18 · Python profesional (`experto`)
Arquitectura y diseño: principios SOLID en Python, patrones de diseño idiomáticos (estrategia con funciones, fábrica, observador, adaptador, inyección de dependencias sin frameworks, repositorio), capas y separación de responsabilidades, configuración (variables de entorno, `tomllib`), `logging` profesional (handlers, formatters, `dictConfig`, logging estructurado), CLI con `argparse` (subcomandos) y mención de Typer/Click, empaquetado y publicación (`pyproject.toml`, build backends, versionado semántico, PyPI, `uv build/publish`), seguridad (validar entradas, secretos, `secrets`, `hashlib`/`hmac`, inyección SQL, `pickle` inseguro, deserialización, `subprocess` seguro), HTTP con `urllib` (y `requests`/`httpx` explicados), acceso a datos con `sqlite3` y mención de ORMs (SQLAlchemy). Ejercicios: CLI con argparse probada con `parse_args([...])`, configuración desde TOML, logger con formato propio, repositorio sobre sqlite3 con inyección de dependencias, hashing de contraseñas con `hashlib.scrypt`/pbkdf2 + `hmac.compare_digest`, patrón estrategia/observador.

### s19 · Proyecto final y ecosistema (`experto`)
Mapa del ecosistema y cuándo usar cada cosa: web (FastAPI, Django, Flask), datos y ciencia (NumPy, pandas/Polars, Matplotlib, Jupyter), IA/ML (scikit-learn, PyTorch), automatización y scripting, DevOps. Explicado con ejemplos no ejecutables (salvo lo que funcione con la biblioteca estándar). Metodología de un proyecto real: requisitos, diseño, pruebas primero, iteraciones, refactorización, documentación, `README`, control de versiones con Git (conceptos), revisión de código. **Proyectos integradores** (varios ejercicios de nivel `proyecto`, grandes y con muchos tests) que combinan todo el curso usando solo la biblioteca estándar: p. ej., gestor de tareas con persistencia en SQLite y CLI, motor de análisis de logs con generadores y estadísticas, mini intérprete de expresiones aritméticas (tokenizador + parser recursivo), sistema de inventario con dataclasses, validación y reportes CSV/JSON, planificador asíncrono de trabajos. Hoja de ruta profesional: portafolio, entrevistas (tipos de preguntas), cómo seguir aprendiendo, contribuir a open source.

### s20 · Examen final y certificaciones (`extra`)
2 lecciones: (1) Certificaciones del Python Institute (PCEP, PCAP, PCPP1/PCPP2): qué cubre cada una, formato, precio aproximado y cómo se relaciona este curso con ellas (verifica datos en pythoninstitute.org / OpenEDG); (2) estrategia para exámenes de programación y entrevistas técnicas (leer código, "¿qué imprime?", gestión del tiempo, trampas típicas de Python). Ejercicios: 6–8 retos finales cronometrables de nivel `dificil`. Quiz: **≥ 90 preguntas** de repaso de todo el curso con campo `topic` = id de la sección (`s01`…`s19`), repartidas según el peso de cada una, mucho "¿qué imprime este código?", trampas clásicas (mutables por defecto, `is` vs `==`, closures en bucles, copias, alcance, MRO, generadores agotados, precisión float…).

## Cantidades mínimas por sección (s01–s19)
- 5–7 lecciones (cada una con `goals` y `takeaways`, bloques variados, **al menos 2 ejemplos ejecutables `"run": true`** salvo que el tema no lo permita, callouts de errores típicos).
- ≥ 5 diagramas Mermaid útiles (modelo mental, flujo, jerarquías, secuencias…).
- **12–16 ejercicios** autocorregidos progresivos: ~4 `facil`, ~5 `medio`, ~3 `dificil` y **1–2 `proyecto`** (más largo, varios pasos, ≥ 8 tests). Cada uno con ≥ 3 tests (normales, bordes, errores), 1–3 pistas progresivas y explicación.
- ≥ 20 flashcards.
- ≥ 30 preguntas de quiz (single/multi/yesno), incluyendo "¿qué imprime este código?" con el código en `código` inline o en el enunciado.
- `sources` con las URLs que realmente consultaste.
